# Three minute demonstration

Show one synthetic job from request to reviewed plan and exception recovery. Use the owned `samples/demo-block.stl`, a future deadline, and a fresh rehearsal database.

| Time | Demonstration |
| --- | --- |
| 0:00–0:20 | Explain the manual quoting and scheduling problem. |
| 0:20–0:50 | Submit a request to Meta, show a missing-units question, and review the extracted fields. |
| 0:50–1:25 | Upload the actual STL, confirm a supported profile, and obtain a real slice-backed quote. Explain the configured pricing policy without disclosing private business data. |
| 1:25–1:45 | Review and approve a compatible reservation. |
| 1:45–2:35 | Inject an explicitly simulated pre-start outage, review a recovery proposal, and approve replacement. |
| 2:35–3:00 | Show the audit history and close with the operational value. |

Meta performs intake extraction. The scheduler, pricing, recovery search, and message template are application logic. Keep operator approval visible. If only one compatible printer is configured, recovery rebooks that printer after the outage rather than inventing compatible alternatives.

State that slicing is real, outage injection is simulated, customer updates are drafts, and no physical printer is controlled. Do not claim measured productivity improvements or production accuracy without measurements. Trim waiting periods only with a clear caption; do not present fabricated output as a live result.

The local rehearsal launcher emits a fresh prompt path with a future deadline. Private recordings, API keys, local rate snapshots, customer artifacts, and imported settings are excluded from this repository.
